Como confirmar H2 (compra LT67)

Na pasta package-source/fl-tools/hotmart-api/:

npm run smoke:sales-gate -- buyer@email.com
npm run smoke:sales-gate -- --recent
  • Preferir API. Se retornar 403 unauthorized_client, fallback: Sales UI Hotmart + registrar transaction ID no READINESS_GATE.md quando existir.
  • SKU canônico: ENA12H-LT67 product id 8216218.
  • EXEC297 (8220552) não é obrigatório para W1. Sem EXEC → t13 HOLD eterno.

Como executar H3 (enviar e-mail)

  1. Jeff deixa EMAIL-REVISAO-FACTUAL.html + EMAIL-PARA-EXPERT.md + ZIP na pasta revisao-expert-w1/.
  2. Humano abre Gmail packapps.br@gmail.com.
  3. Injeta HTML via paste/ClipboardEvent (Gmail TrustedHTML bloqueia innerHTML / insertHTML / DOMParser).
  4. Anexa o ZIP no Gmail (não dentro do HTML).
  5. Valida: logo ENA12H carrega, go + pay + Club abrem, chip do anexo presente.
  6. Só então envia.

O que H4 não é

  • H4 não é “ligar o checkout”. O checkout já estava live no H3.
  • H4 não é Window 2. Window 2 começa quando o expert responde com correções (ou OK).
  • Sem registro na TIMELINE.md, não inventar “ele já aprovou”.

Proibido em qualquer GO

  • Pedir senha, 2FA ou documentos do expert.
  • Inventar prova, CRM, preço, urgência falsa.
  • Auto-send de e-mail.
  • Empurrar tráfego antes de H5.
